Protocol Roadmap

1. L1 Core Freeze

Заморозка фундамента. Менять только через RFC.

  • Архитектурный аудит
  • MAINNET_CONSTITUTION.md
  • Критические сценарии

2. P2P Network

Node-to-node стабильность.

  • Handshake, peer discovery
  • Presence, snapshot propagation
  • Sync, recovery

3. Bootstrap Infrastructure

Тестовая сеть с мониторингом.

  • Bootstrap nodes: EU, US, Asia
  • Prometheus + Grafana
  • Метрики: peers, epochs, latency

4. Block Explorer

Обозреватель поверх AevumDB.

  • Explorer API
  • Индексатор
  • Latest epoch, slot, supply

5. Wallet Layer

SDK + CLI до GUI.

  • aevum-wallet crate
  • Create/import, sign, verify
  • CLI: create, send, balance

6. Public Testnet

50+ чужих узлов.

  • Sync, recovery
  • Partitions, upgrades
  • Long run testing

7. Mobile Wallet v1

Мобильный кошелёк.

  • Create/import, balance
  • Send, receive, QR

8. L2 Foundation

Масштабирование.

  • Bridge, settlement
  • Proof system, batching
  • Sequencer

9. Developer Ecosystem

SDK и инструменты.

  • Rust SDK, TypeScript SDK
  • REST API, RPC API
  • Документация, примеры

10. Mainnet Readiness

Готовность к запуску.

  • Security audit
  • Load test, recovery test
  • Upgrade test, key rotation

Platform Roadmap

Phase A — Platform Foundation

Фундамент аккаунтов.

  • Register, login, logout
  • Password change, reset
  • Email verification
  • Session management
Status: In progress

Phase B — Community

Сообщество и контент.

  • Профиль пользователя
  • Форум, комментарии
  • Уведомления, поиск

Phase C — Developer Portal

Инструменты разработчика.

  • Docs, API Reference
  • Protocol Constitution
  • GitHub, Downloads

Phase D — Explorer Integration

Реальные данные после P2P.

  • Explorer UI
  • Индексация AevumDB
Requires: P2P Network + Indexer + Explorer API

Phase E — Wallet Integration

Интеграция кошелька.

  • Connect wallet
  • Sign transactions
Requires: Wallet SDK + Testnet

Phase F — Mainnet Launch Portal

Портал запуска сети.

  • Network status
  • Mainnet announcement
Requires: Mainnet Readiness
