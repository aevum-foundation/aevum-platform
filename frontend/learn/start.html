MODEL

Learning Levels and Paths

Learn is organized along two independent dimensions: learning levels and paths. They are different coordinate systems, and they intersect freely.

Learning Levels

Learning levels describe capability: what you can understand, build, and verify. They progress from Explorer through Learner and Builder to Contributor, Core Contributor, and Maintainer.

Paths

Paths describe direction: which technical area you want to explore. There are six paths — Beginner, Rust / Systems, Cryptography, Protocol / Blockchain, Compute / GPU, and Contributor. You can move between paths at any time.

CURRICULUM

The Curriculum

The curriculum is organized into six curriculum levels, from Computer Science through Contributor. They are a recommended progression, not credentials or status levels.

00

Level 0 — Computer Science

How computers work: memory, processes, files, Linux, Git, and a first programming language. For people with no prior experience.

01

Level 1 — Rust and Systems

Ownership, borrowing, async, concurrency, networking, and reading real systems code. For developers with prior programming experience.

02

Level 2 — Cryptography

Hashes, signatures, AEAD, post-quantum primitives, and how cryptography is used in protocols.

03

Level 3 — Distributed Systems and Blockchain

Consensus, state machines, L1/L2 separation, and coordination without central authority.

04

Level 4 — Aevum Architecture

Aevum's L1/L2 split, Compute Engine, AevumDB, post-quantum stack, and verification.

05

Level 5 — Contributor

How to turn capability into real contribution: finding work, opening a first PR, getting review.

PROCESS

How to Actually Start

Four practical steps. No schedule, no graduation, no permission required.

Pick a level that matches where you are

If you're new, start at Level 0. If you've written code before, start at Level 1. If you already know Rust and cryptography, jump directly to Level 3 or Level 4.

Read the topics for that level

Each level has a list of topics in the curriculum. Read them at your own pace.

Practice

Real understanding comes from building things. GitHub issues, discussions, code, documentation, testing, and other project work are places to apply what you learn.

Move up when you're ready — or stay where you are

There is no schedule. There is no graduation. Some people spend years at one level. That is normal and accepted.

PREREQUISITES

What You Do NOT Need

To start learning with Aevum Learn, you do not need:

No prior experience

If you've never programmed, Level 0 exists for you.

No degree

No credential is required to learn or contribute.

No permission

You don't need to be accepted, invited, or approved by anyone.

No payment

Learn is open. There is no paid tier, no gated content, no token requirement.

No commitment

You can read one page, close the tab, and come back in a year. That is fine.
