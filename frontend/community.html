Participation

  • Inspect the implementation

  • Ask technical questions
  • Challenge design decisions
  • Share architecture ideas

  • Help answer questions
  • Improve documentation
  • Share useful knowledge
Community Rules

Build with respect.

Simple principles for keeping technical discussion useful and the community welcoming.

RULE / 01

Respect people

Debate ideas directly without attacking the people behind them.

RULE / 02

Prefer evidence

When discussing protocol behavior, code, tests and reproducible evidence come first.

RULE / 03

Keep it constructive

Report problems clearly and, when possible, help move the discussion toward a solution.

RULE / 04

No false claims

Do not present planned features, experiments or unverified information as completed facts.
